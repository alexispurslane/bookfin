Controlled diagnostic reproduction

The committed fixture diff is deliberately small. Diagnostic code is archived
instead of adding a public clock argument or a generic builder test framework.

1. Use the pinned Nix shell and flutter pub get in an isolated checkout of the
   original base 5c8c92ecd348a7fb7c51ab176da6e616cfd2aa1c.
2. Copy archive-4.0.9 from the package_config archive root to a private directory.
   Never patch the shared Pub cache. Apply dependency.patch.gz to that copy.
   Its only semantic change is the lazy lastModTime default: a Dart Zone value
   can supply a DateTime; an absent value retains DateTime.now(). Explicit
   lastModTime assignments and ZipEncoder.modified overrides are unchanged.
3. Save .dart_tool/package_config.json byte-for-byte. Change only archive's
   rootUri to the private copy. The archived before-config is evidence from
   this machine, not a portable replacement package configuration.
4. Expand timestamp_diagnostic_test.dart.gz into
   test/reader/epub/timestamp_diagnostic_test.dart. Append the temporary
   diagnosticBook function shown in patches/02-controlled-red.patch.gz to
   damaged_chapters_test.dart. It calls the real private _book; no clone of
   that builder is tested.

   clock control and seven content-sensitivity tests pass; the seven time-
   stability assertions fail. Every build is independent. No sleeps, clock
   boundary waits, fixture inflation, caching or reader changes are involved.
