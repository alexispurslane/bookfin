# Make the OCR viewport test wait for the page instead of a fixed 30 ms

test/reader/ocr_viewport_test.dart, 'recognition stops when the person chooses the original page, which stays visible', waits 30 ms of real time and then expects the semantics label 'Original source page 1' (line 162). In a full run with --concurrency=4 at a load of about 21 on 10 cores (branch t3/30cd0bb4, 2026-11-11), the label was not there yet and the test failed. The file passed 3 of 3 runs alone. Wait until the page shows, with a limit, as settleNative or settleReader do, instead of a fixed delay.
