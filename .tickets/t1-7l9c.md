# A saved place in text with few spaces, such as Chinese, can open a later page

Found in tc-4f3q (corpus run). wordStart (lib/reader/epub/places.dart) copies epub.js: the saved place of a page is the start of the first space-delimited range at or after the page's first character. Text without spaces between words, such as Chinese, has few spaces. When the next space in the text node lies beyond the page's end, the saved place opens a later page. The WebView reader had the same fault.

Measured: Gutenberg's Hong Lou Meng (pg-24264, Chinese, about one space per 100 characters) at 360 x 640 at 26 pixels: 53 of 2,782 page starts open a later page (one or two pages later), for example epubcfi(/6/6!/4/8[id00030]/1:967) saves section 2 page 84 and opens page 86. At 412 x 671 at 20 pixels, all 1,368 page starts open their own page. Every other corpus book opens every page start on its own page. A person who reads such a book loses one or two pages of place at each save, which AGENTS.md counts as data loss.

Product fork (the design says that a saved place equals the JSON that epub.js wrote for the same page start, E4 and E18):
- Design A: keep epub.js's place only when it opens the same page; otherwise save the page's first visible character. Saved JSON stays equal to epub.js's wherever epub.js was right. Cost: a second rule in wordStart, and the equality test needs an exception for these pages.
- Design B: always save the page's first visible character (after leading white space). Simplest rule, never opens another page. Cost: new saves differ from epub.js's anchors for most pages of every book; old places still open, but the E4 and E18 equality tests change meaning.
Either way, placeOf must keep opening places that epub.js saved.

## Acceptance Criteria

- The user or the orchestrator picks design A or B.
- Every page start of Hong Lou Meng at both corpus page settings opens its own page (BOOKFIN_EPUB_CORPUS=1 flutter test test/reader/epub/corpus_test.dart --plain-name pg-24264-hong-lou-meng).
- The places that epub.js saved (test/reader/epub/saved_places_test.dart) still open on their pages.
