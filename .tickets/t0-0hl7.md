# Let the recognition cache trust the digest from Downloads instead of hashing the PDF again

The first recognition cache access of each opened PDF hashes the whole original file in a hop (_matches in lib/reader/ocr_storage_io.dart), to make sure that its bytes still have the original digest. Downloads already makes sure of this at each lookup of readLocalFile (_verified, by the file's size and modification time, with a full hash only when they changed). So the cache check reads the whole file a second time. The read lease (PdfTextLease in lib/reader/pdf.dart and its owner in lib/reader/session.dart) gives the cache only the file's Uri. Give it the VerifiedFile, so that the cache uses the digest that Downloads gives, and remove _matches and _lastCheck. Found during t6-doxp.

## Acceptance Criteria

The first cached or recognized page of a scanned PDF does not hash the original file, and a page that was recognized before the change still finds its cached text.
