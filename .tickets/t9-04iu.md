# Resolve original downloads for alternate media sources

The verified downloader uses Jellyfin Items/{id}/Download, which selects the item original rather than a requested mediaSourceId. It fails closed for a non-default or non-first media source instead of downloading the wrong recording. Determine a supported, freshly authorized original-source route without a File fallback after Download denial. Keep the existing SourceFile identity model; do not add a server component.

## Design

docs/plans/bookfin.md; docs/downloads.md

## Acceptance Criteria

Synthetic tests prove that the chosen source bytes match the selected source identity, including ordinary-user policy denial and no permission-bypassing fallback. Coordinate real-source acceptance with boo-2cgp.
