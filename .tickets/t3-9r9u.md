# Handle EPUB SVG assets in the approved reader integration

The November 2 Android finite probe converts the public-domain pg11-kf8.mobi successfully and displays its text. EPUBX exposes OEBPS/flow00004.svg as its first image, 324 bytes. Flutter Image.memory rejects that SVG with Exception: Invalid image data. JPEG resources remain valid. The compatibility parser proof is not a MIME-aware EPUB navigator; do not treat this as MOBI conversion corruption or silently skip the failed asset.

## Design

docs/plans/bookfin.md; docs/research/reader-formats.md; tool/research/readers/evidence/android-runtime/kf8.png and logcat.txt. Keep SVG inside the chosen passive-content boundary. Parent owns reader/package approval.

## Acceptance Criteria

The chosen Android EPUB navigator handles the converted KF8 SVG reference offline, or explicitly identifies an unsupported-image fallback while retaining readable text and source resources. Prove PNG/JPEG rendering and resource associations separately. Block SVG active content and remote requests. No unapproved SVG engine is selected by this ticket.
