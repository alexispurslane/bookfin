# Place a reading place of the PDF text view inside its page for cross-edition landings

t9-nl30 places a PDF reading place at the start of its source page, because a place in the original page view names only its page. A place of the PDF text view also names a character of the page's text. The text outline could keep each page's text length, so that the place lands at its share of the page. A PDF page holds about 3 phone pages, so a reading place at the end of a page now lands up to about 3 minutes early in the audiobook. The page's text can come from recognition, whose length the text layer does not know.
