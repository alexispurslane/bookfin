# The reader screen rebuilds per signal, and its panels report choices to the screen

Rules: UI rule 1 (only controllers cause side effects). UI rule 2 (one component for each kind of thing). UI rule 3 (subscribe at the lowest level).

Breaks:
- lib/reader/screen.dart, _ReaderScreenState.build: a ListenableBuilder on the whole ReaderSession rebuilds the Scaffold, the viewport widget, the controls and the embedded mini player on each page turn and each save.
- lib/reader/screen.dart, _ContentsPanel: calls reader.goToContents and pops.
- lib/reader/screen.dart, _SearchPanel: calls reader.search and reader.openHit, and calls reader.cancelSearch in dispose.
- lib/reader/screen.dart, _BookmarksPanel: calls reader.restoreBookmark, shows its own AlertDialog bookmark editor and calls reader.editBookmark.
- UI rule 2: the AlertDialog in _BookmarksPanel duplicates the audio bookmark editor. _panel uses showModalBottomSheet, and the rest of the app uses showGlassSheet.

Target design:
ReaderScreen is the controller. The panels become leaves that report onContents(href), onSearch(query), onOpenHit(hit), onCancelSearch, onRestore(bookmark), onEdit(bookmark) and onDelete(bookmark). The screen pops, calls the session, and opens the shared bookmark editor from the player ticket. Each part subscribes to its own reader listenable from the reader signals ticket: the page label and the progress bar to place, the panels to bookmarks or search, the viewport to document. The panels open through the app's one sheet component. If the reader needs a plain surface over the page, add that as a parameter of showGlassSheet, so there is still one sheet component and the reader looks the same as today.

Owned files: lib/reader/screen.dart, lib/catalog/glass.dart (only for a sheet parameter), and their tests.

## Acceptance Criteria

- A page turn rebuilds the page label and the progress bar, and not the viewport widget or the controls row (rebuild counters).
- A contents choice reports onContents. The screen pops, then navigates.
- A bookmark edit opens the shared bookmark editor, and the screen saves the result.
- No reader panel calls ReaderSession (a fake that throws proves it).
- The reader panels look the same as before (golden or widget test of the surface color).
