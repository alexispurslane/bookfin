# Stop keeping a book's font files in its admitted record

Since boo-iv7q the reader never reads a book's font files. Admission (lib/reader/epub/publication.dart) still keeps them in the admitted record beside the images (_binary, _types, the manifest font check at _font and _fontMime), and the record format still counts them. Dropping them shrinks each record and its write. It changes admission's output, so it needs a new Publication.revision, and the revision is part of the identity that keys page maps. Decide whether the smaller record is worth one re-admission and one page map rebuild of every book. The WebView document policy (font-src) is a separate question.
