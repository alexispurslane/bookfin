# Downloads creates a storage directory only for a source that saves something

Found during t9-4jqk on 2026-11-07. LocalDownloads._restore (lib/downloads/local_downloads.dart) calls _safeDirectory for every bound source of the library on each bind whose signature changed, and then looks at each directory's manifest, complete and partial files. A library of 20,000 sources therefore creates 20,000 empty directories and makes about 100,000 storage calls in the background after each catalog change. The work is asynchronous, so it does not block the UI isolate, but it delays restoration and the first queued download.

Target: restoration lists the account directory once and builds records for the sources that have a directory. A source without a directory starts as an empty record, and the first request or write creates its directory. checkInvariants and _save keep their containment checks.

## Acceptance Criteria

A bind of a library with 1,000 sources and no saved files creates no source directory (test). A request for one source creates only that directory. Restoration of saved, partial and failed records keeps its current results (existing tests).
