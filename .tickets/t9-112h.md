# The reader session publishes narrow change signals

Rules: UI rule 3 (narrow change signals).

Breaks:
- lib/reader/session.dart, ReaderSession: one notifier carries the visible address (each page turn), loading and ready state, the message, bookmarks, search hits and the font size. ReaderScreen rebuilds the whole screen, the viewport widget included, on each page turn.
- lib/reader/session.dart, _retryPending: calls _emit after every write, so one page turn notifies twice.

Target design:
ReaderSession keeps its ChangeNotifier and adds narrow listenables:
- place: the visible address.
- document: book, edition, publication or document, loading, ready, message and warnings.
- bookmarks: the bookmarks of the open edition.
- search: searching, hits and error.
- fontSize.
- saveStatus: whether the account has a failed write.
A write that changes no visible state notifies nothing. The reader screen ticket moves the screen to these listenables.

Owned files: lib/reader/session.dart and its tests.

## Acceptance Criteria

- A page turn notifies place once and notifies no other reader listenable.
- A completed write that does not change the save status notifies nothing.
- Adding, editing and deleting a bookmark notify bookmarks.
- The existing reader session tests pass.
