# Measure the first PDF text outline time on a phone

t9-nl30 measures a PDF's text outline on pdfrx's worker isolate. It opens the file and reads all the bookmarks in one step, then counts each page's text layer in slices of about 8 ms. Go to on a listening place in a PDF waits for this outline, and so does the first page that the reader draws while one slice runs. Nobody measured the time on a phone. Measure, on the Android emulator or the user's phone with the user's consent, a long PDF with a text layer (500 pages or more) and many bookmarks: the time to the first outline, the longest wait of a page draw while the outline runs, and the wait of Go to. If Go to waits more than about one second, decide with the user whether to show a progress state or to start the outline when the book opens.
