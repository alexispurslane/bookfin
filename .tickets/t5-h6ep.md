# Show the generated cover colors behind Android's media player for a book without a cover image

The player chip blurs a generated palette (coverPalette) for a book that has no cover image. Android's media player then gets no art (boo-lxzv hands it only the blurred copy of a real cover), so it draws its plain background. Make a blurred palette image for such books, kept and written the same way as the blurred cover in DiskCovers.blurred.
