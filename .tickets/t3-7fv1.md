# Prove or reject Bookfin-owned private playlists as a sync index

Disposable Jellyfin 12.4.0 proves ordinary owners can create, privately discover, update a 64 KiB name payload, and delete independent private playlist objects. Cross-user read/write/delete returns 404. Shared CustomPrefs/Enhanced snapshot failures do not reject this distinct candidate. Before final boo-p58t selection, either prove a complete app-owned private-playlist journal or record a concrete blocker: operation deduplication after lost acknowledgments, deletion fencing after compaction, bounded history/replica retention, paging under concurrent changes, existing-client coexistence, and upgrade compatibility. No plugin is selected. See docs/research/jellyfin-sync.md.

## Acceptance Criteria

Parent records the existing-storage versus accepted small-plugin decision without claiming all existing protocols impossible. Do not overload fields in another client record or silently relax offline/deletion/history promises.
