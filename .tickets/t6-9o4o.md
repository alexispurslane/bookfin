# Show the bottom border and padding of a box that closes at the end of a section

Found in te-orei. LayoutRun._cut ends a section's last page at the bottom of its last slice. A box that closes after that slice draws its bottom border below the page's bottom, so _publish leaves the rule out. Example: a table with borders, or a bordered div, as the last thing in a section shows no bottom border. Chromium shows it. The last page could end at the strip position after the last BlockEnd (the run's _y), which keeps the page-start property because only the last page changes.
