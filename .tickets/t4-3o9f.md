# Make a download removal wait for the page map writes of an open book

BookPageMaps.write (lib/reader/epub/page_maps.dart) writes into the download's layout directory while the book is open, outside any Downloads.readLocalFile. A removal of the download during such a write can fail with 'Directory not empty', or the write can make the layout directory again after the removal deleted it, so the download folder stays with a stray map. Found by boo-yjq6, whose admitted record write had the same race and now holds the download through ReaderSession.derivedWrites. The survey writes already lease the download (SurveyFiles, ReaderSession._lend). Give page map writes the same lease.
