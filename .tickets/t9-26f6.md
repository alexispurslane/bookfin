# Add Android SDK 35 for reader native packaging

The boo-73yj isolated Flutter APK proof found that pdfrx 2.11.0 pulls in jni with compileSdk 35. The shared flake provides platform 36 only, so Gradle tries and fails to install platform 35 into the immutable Nix store. The research-specific Android shell proves that platforms 35 and 36 build the APK. Add platform 35 to the shared project-managed SDK during reader integration without overwriting a user SDK or changing shell profiles. Readium 3.4.0 additionally documents compile SDK 37, but that engine is not selected and SDK 37 is not part of this ticket.
