# Make the reader's bottom controls take less space

User request (2026-11-08): the reader's bottom area stacks four rows (tool icons, the scrub bar, the chapter arrows with the place label, and the mini player), about a quarter of the screen (docs/screenshots/reader-epub.png). Redesign it to take much less space while keeping every function reachable. Design chosen by the user in chat on 2026-11-08; see the note.
