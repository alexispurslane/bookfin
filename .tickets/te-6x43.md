# Remove network font fallback from the development browser gallery

T3 browser review of the new gallery at loopback port 7358 loaded bundled Outfit.ttf and SourceSerif4.ttf locally, but Flutter web also fetched default Roboto and Noto symbol/script fallback fonts from fonts.gstatic.com. Android uses bundled primary fonts and installed system fallback; no Android font service or network permission was added. Browser preview must not be represented as fully offline until its framework fallback assets are bundled/configured. Do not replace approved typography with another family.

## Acceptance Criteria

Browser gallery renders representative Latin, Greek, Cyrillic, Japanese, Arabic, and control glyphs with external font requests blocked; licenses and provenance accompany any extra bundled fallback assets. No changes to the approved HTML mockup.
