# Keep the app's one-value preferences behind one store type

Found by boo-yjq6 on 2026-11-11. Three stores keep one short text value in SharedPreferencesAsync with the same two-method interface: AppearanceStore (lib/appearance/preferences.dart), ReadingSpeedStore (lib/reader/reading_speed.dart) and PageSettingsStore (lib/reader/last_page_settings.dart). Replace them with one store type that takes its key, and one memory store for tests. About 17 files use the first two.
