# Run record-store-driving widget tests in real time, then lower the record store hop limits

From t6-n8y3. lib/playback/store.dart keeps _hopItems = 16 and _hopText = 4 KiB as a compromise, because widget tests run in fake time, in which an isolate hop never completes. Its own comment says that a hop pays from about four actions or eight records. t6-n8y3 added test/real_time.dart (finish and runUntil), which runs real and fake time in turns until work ends. Drive the record-store operations that widget tests await through that helper, measure the break-even point in AOT, and lower both limits to it.

## Acceptance Criteria

Every widget test that awaits a record-store operation passes with the record store limits at the measured break-even point, and a test locks in the new limits through behavior.
