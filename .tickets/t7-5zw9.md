# Make the macOS acceptance run pass when the app container holds records from an earlier run

tool/bookfin accept-macos failed three times on 2026-11-08 (tc-1yif) at 'Personal records: sync twice': it timed out waiting for 'Sync now', and the screen said '1 choice waits | Synced 7:53 PM'. The steps before it passed, including the new EPUB step. The run deletes the saved sign-in but not the app's records in its sandbox container, and a failed run never reaches Sign out. So a later run starts with the fixture's sync choice already waiting (the second run also showed 'The saved audio source changed'). The fixture keeps its sync state in memory, and each of these runs used a freshly started fixture. Make the run independent of earlier runs, for example by starting from an empty records store, or by resolving or expecting a waiting choice. Check whether the sync step also fails on main from a clean container.
