# Exact normal-app Android acceptance

Read `docs/evidence/reader/android-normal-formats-20261103.md` for outcomes,
exact artifacts, scope, command recoveries, cleanup, and remaining gates.

This directory records the normal APK from source
`4ae8c6c2299e7ec7c16420663a8fc305e87e6c9a`, not an OCR or standalone reader
probe. Ordinary PDF/MOBI admission fails and is tracked as `t3-jrhf`.
EPUB and a few real normalized Android records have separate bounded proof.

`readback.py` reads only an owned account from copied Android SQLite files.
`server_readback.py` reads the same existing packaged plugin API for the
disposable ordinary accounts. Both require private marker/account files that
are deliberately removed after audit. They cannot authorize a live server or
represent a second Android device. No fixture credential belongs in Git.

`evidence-checks.json` compares exact retained payload hashes and tables, not
physical writes or performance. Native replacement, authentic old-schema
migration, complete format acceptance, conflicts/history on two Android
devices, TalkBack, physical-device behavior, and compliance remain unproved.
